# Asset policy

Use local staged media only. Record the source page, creator/page label when
available, license/rights text, attribution note, claim links, and one of:
`known-compatible`, `attribution-required`, `unknown`, `restricted`.

Do not bypass authentication, paywalls, DRM, watermarks, rate limits, or a
host's automated-access rules. Check applicable robots rules before automatic
crawling; robots controls crawler access, not reuse rights.

When suitable media is unavailable or ambiguous, build an original SVG/HTML
visual and mark it `illustrative`. `unknown` and `restricted` media may remain
in review and delivery only with a visible warning. Do not publish automatically.
