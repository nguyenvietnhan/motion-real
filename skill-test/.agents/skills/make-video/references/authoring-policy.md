# Authoring policy

Author fresh HTML/CSS/GSAP from `video-plan.json`, `timing.json`, and local
asset paths. Each state change must perform the narration's idea through an
object, process, camera, crop, layer, or diagram transition.

Each primary shot is an element tagged with its `data-beat-id`, `data-shot-id`,
`data-focal-id`, `data-visual-family`, `data-non-caption-text`, and the local
`data-asset-id` values it visibly uses. Its declaration must agree with the
corresponding `visual_shot` and referenced assets in the plan.

Choose a visual language from the brief and beat-specific visual metaphors. Do
not cycle fixed layout forms, use a default style pack, copy prior job code, or
add global motion to satisfy a freeze detector. Do not repeat a global HUD,
header/footer, enclosing panel, grid, or headline merely as decoration.

Intentional stillness is valid for comprehension. It must be represented in the
beat's state plan. Use fades only when their transition intent is documented;
they are not the default scene boundary.
