# Motion doctrine

Review a beat against its narration and declared state changes:

- Identify the focal object and the story-state change a viewer should see.
- Prefer causal continuation between beats when it helps comprehension.
- Reject motion used only to create pixel churn: scanline, decorative pulse,
  universal drift, idle wobble, or unrelated camera movement.
- Preserve intentional stillness when it gives a key idea time to land.
- Treat transition choice as a beat-specific decision; neither fade nor a hard
  cut is universally required.

Return notes for `qa.json`; do not change approval policy or make a render gate.
