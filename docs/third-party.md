## Runtime and build dependencies

Installed via npm (see root `package-lock.json` for exact versions). Notable
components include:

| Component | Typical role | License (see package) |
| --- | --- | --- |
| [Remotion](https://www.remotion.dev/) (`@remotion/*`) | Composition, bundling, render | Remotion License / package terms |
| [Electron](https://www.electronjs.org/) | Desktop shell | MIT |
| [React](https://react.dev/) | UI and scene modules | MIT |
| [Zod](https://zod.dev/) | Schema validation | MIT |
| `ffmpeg-static` / `ffprobe-static` | Audio measure / mix helpers | GPL-compatible binaries per package |
| `undici`, `pino`, `@mozilla/readability`, `linkedom`, … | Pipeline helpers | See each package |

Run `npx license-checker --summary` (or similar) on a clean install if you need
a machine-generated report for compliance reviews.

## Vendored fonts

Render-safe fonts are vendored as base64 WOFF2 data URLs in
`packages/blocks/src/vendor-fonts.generated.ts` (generated by
`scripts/vendor-fonts.ts` from `@remotion/google-fonts`). Families used:

| Family | Upstream | Common license |
| --- | --- | --- |
| Inter | [rsms/inter](https://github.com/rsms/inter) / Google Fonts | SIL Open Font License 1.1 |
| Be Vietnam Pro | Google Fonts | SIL Open Font License 1.1 |
| Cascadia Mono | [microsoft/cascadia-code](https://github.com/microsoft/cascadia-code) / Google Fonts | SIL Open Font License 1.1 |

Font software is not re-licensed as MIT application code; keep OFL notices when
extracting or redistributing the font files alone. Re-run
`npx tsx scripts/vendor-fonts.ts` only when intentionally refreshing fonts.

## External services and development runtimes (not shipped)

- Desktop AI chat depends on a **9router** (or compatible) gateway process on
  `localhost:20128`. That binary is **not** vendored in this repo; install and
  license it separately.
- Video Agent developer preview embeds a native **DeepSeek Harness** process
  (development checkout at `../deepseek-harness` or via `MOTIONREAL_DSH_CLI`).
  DeepSeek Harness is governed by its own repository license.
- Cloud TTS may call **Vivibe/LucyLab** or **ElevenLabs** with user credentials —
  those services are governed by their own terms of use.
- **VieNeu Local** developer preview runs `vieneu==3.3.0` via Python 3.11 with ONNX
  runtime models cached from Hugging Face under `.video-tool/vieneu/huggingface`.
  The package and model weights are governed by VieNeu's Apache-2.0 / open license terms.
